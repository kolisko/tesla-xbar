# Example configuration

[`config.example.json`](config.example.json) documents the non-secret configuration fields: Tesla Client ID, public-key domain, region, OAuth callback URI and display mode. All account-specific values are placeholders.

Use **Settings…** in the installed plugin to configure your own application, following the [setup guide](../docs/SETUP.md). The installer does not copy this example over an existing profile.

The live configuration stays in `~/Library/Application Support/Tesla xBar/config.json`. Client Secret and OAuth tokens stay in macOS Keychain. Do not replace this public example with your personal configuration.
